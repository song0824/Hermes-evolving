# 中国法定节假日检测

共享节假日日期列表和检测函数，供多个 cron job 使用。

def is_china_holiday(d=None):
    from datetime import date
    if d is None:
        d = date.today()
    return d.isoformat() in CHINA_HOLIDAYS

## 使用模式

在 cron job 或脚本开头添加检查：

```python
if is_china_holiday():
    # 根据任务类型选择行为：
    # - 文档创建类 → 发送节日祝福
    # - 催填/提醒类 → 静默跳过 (print("SKIP|..."); exit())
```

## 更新维护

国务院每年 11-12 月公布次年节假日安排。新增年份时：
1. 搜索"国务院办公厅关于XXXX年部分节假日安排的通知"
2. 将放假日期 + 调休上班日加入集合
3. **注意**：调休补班日（周末上班）不属于节假日，不应加入
